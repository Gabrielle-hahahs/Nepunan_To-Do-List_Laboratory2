# To-Do

A small to-do list website made with React and Tailwind CSS. The layout uses a calm garden-inspired color palette and a simple task list.

## Run the project
1. Install Node.js.
2. Open this folder in your code editor.
3. Open the terminal in this folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local address shown in the terminal.

## Publish the website
You can push this folder to GitHub and import the repository into Vercel. Use `npm run build` as the build command and `dist` as the output folder.

## Included features
- Add a task
- Mark a task Done or Not Done
- Delete a task
- Clear the whole list
- Show or hide a short user guide
- Responsive layout

Tasks are stored in React state, so they will reset when the page is refreshed.
